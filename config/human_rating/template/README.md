# Motivation 

This folder contains materials for rating Archetypometrics trait differentials against moral foundation categories.

## Files

- `trait_foundation_rating_template.tsv`: Rating sheet with one row per trait differential.
- `foundation_definition.txt`: Short definitions of each moral foundation.
- `foundation_dictionary.txt`: Reference dictionary of moral foundation terms.

## Columns

The template includes the following rating columns:

- `care`
- `fairness`
- `loyalty`
- `authority`
- `purity`
- `liberty`
- `general`

Use `general` for traits that seem related to overall moral goodness or badness, even if they do not fit clearly into one specific foundation.

## Scale

For each rating column, enter:

- `+1`: the trait differential is related to the foundation.
- `-1`: the trait differential is not related to the foundation.

Please use only `+1` or `-1` in the rating columns. Leave explanatory comments only in the `notes` column.

## Instructions

Each row gives a bipolar trait differential, such as:

```text
cruel :: kind
loyal :: traitorous
debased :: pure
strict :: lenient
```

Rate whether the trait pair as a whole is conceptually related to each moral foundation. The rating should reflect relevance to the foundation, not whether one pole is morally good or bad.

For example:

- `cruel :: kind` is likely related to `care`.
- `loyal :: traitorous` is likely related to `loyalty`.
- `debased :: pure` is likely related to `purity`.
- `strict :: lenient` may be related to `authority`.

If a case is ambiguous, use your best judgment and add a brief note in the `notes` column.

Some tips:

- Use foundation_definition.txt and foundation_dictionary.txt as references 
to rate from that perspective rather than your intuition alone. 
- Try to complete the  rating task in a few sittings as possible so the judgments stay consistent across. 
- Sometimes only one pole of a differential clearly matches a foundation. We aim to rate the trait pair as a whole is conceptually related to each foundation but feel free to add a brief note about which pole matched.

# Purposes 

Completed rating files will be compared across raters to measure agreement. The agreed-upon trait mappings will then be used to build the final moral foundation configuration for the project.
